# BFA-Playbook

This project demonstrates a basic SSH brute-force attack detection and response
workflow in a Linux environment. The focus of this project is on understanding
logs, detecting suspicious activity, and documenting response steps, similar to
a SOC analyst’s work.

## What this project includes
- SSH brute-force attack simulation using a test user
- Detection of failed login attempts using system logs
- Simple Bash-based detection logic
- Basic response actions after detection
- Evidence collection (logs, screenshots, timeline)
- Final incident report

## Tools and technologies used
- Linux (Kali Linux)
- SSH
- journalctl
- Bash scripting

## Project structure
- Project overview and playbook
- Lab setup
- Attack simulation
- Detection logic and script
- Response actions
- Evidence
- Incident report

## Purpose
This project was created for learning and practice purposes to understand how
brute-force SSH attacks are detected and handled from a defensive (blue team)
perspective.

## Note
All activities were performed in a controlled lab environment using test
accounts. No real systems or users were targeted.
