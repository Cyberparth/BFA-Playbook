# Project Architecture

## Overview
This project follows a simplified SOC incident response workflow
focused on brute-force authentication attacks.

## Flow
1. Authentication logs are generated by the system
2. Logs are monitored for failed login attempts
3. Detection logic identifies suspicious patterns
4. Incident is classified using the IR playbook
5. Response actions are executed
6. Evidence is collected and documented
7. Incident report is generated

## Key Components
- Log Source: Authentication logs
- Detection Layer: Threshold-based logic
- Response Layer: Playbook-driven actions
- Documentation Layer: Evidence and reports
