# Project Scope – Brute-Force Incident Response Playbook

## Objective
The objective of this project is to design and simulate a structured
incident response process for a brute-force authentication attack.
The project demonstrates detection, analysis, containment, and
documentation following SOC best practices.

## Incident Type
- Brute-force login attack against an authentication service

## In-Scope
- Failed authentication attempts
- Log-based detection
- Incident response playbook
- Evidence collection and reporting
- Safe, ethical simulation in a lab environment

## Out-of-Scope
- Real-world exploitation
- Attacking external systems
- Production environments
- Zero-day vulnerabilities

## Assumptions
- Logs are reliable and available
- Attack is detected at the authentication layer
- Response actions are simulated where necessary

## Constraints
- Single incident type
- Single detection mechanism
- Local or virtual lab environment
