# Lab Environment Setup

## Purpose
This lab environment is designed to safely simulate and analyze
a brute-force authentication attack without impacting real systems.

## Operating System
- Linux-based system (Local machine or Virtual Machine)
- SSH service enabled for authentication logging

## Log Sources
- /var/log/auth.log  
  Used to monitor authentication attempts and failed login events.

## User Accounts
- Test user account created for simulation purposes
- No real user credentials are used

## Network Scope
- Localhost or internal network only
- No external or production systems involved

## Tools Used
- System authentication logs
- Terminal for log inspection

## Security & Ethics
- No real brute-force attacks are performed
- Failed login attempts are manually generated
- All activities are conducted in a controlled lab environment
